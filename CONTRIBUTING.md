# Contributing

Report bugs and propose changes on [Codeberg](https://codeberg.org/wvhulle/lazaret/issues). Pull requests are welcome.

Commit messages follow [Conventional Commits](https://www.conventionalcommits.org/), for example `fix(scan): keep the toast open long enough to act on`. CI checks them on every pull request, and release-plz builds the changelog from them.

Before you start:

- [Development](docs/development.md): the dev shell, tests, VM tests, screenshots, translations, packaging, and the rules every change follows.
- [Architecture](docs/architecture.md): the components and the safety rules behind scanning, quarantine and live tuning.
